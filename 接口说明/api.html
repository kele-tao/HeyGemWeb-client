HeyGem AI API

核心服务

获取所有数据 保存所有数据

模型与合成

克隆声音模型 上传数字人形象 文本合成音频 试听声音(缓存)

API 文档

欢迎使用 HeyGem AI 数字人后端服务。本文档详细说明了所有可用的 API 接口、参数和返回示例。

GET

/api/data

获取应用的所有持久化数据，包括声音模型、数字人形象和已生成的视频列表。

成功响应 (200)

返回一个包含所有数据的 JSON 对象。

{
  "voices": [],
  "avatars": [],
  "generatedVideos": []
}
curl --request GET --url http://localhost/api/data
import requests
response = requests.get("http://localhost/api/data")
print(response.json())
import fetch from 'node-fetch';
fetch('http://localhost/api/data')
  .then(res => res.json())
  .then(json => console.log(json));
POST

/api/data

保存应用的所有状态数据。前端在数据变更时（如增删改）调用此接口进行持久化。

请求体

请求体结构应与 GET /api/data 的响应结构完全一致。

{
  "voices": [ /* ... */ ],
  "avatars": [ /* ... */ ],
  "generatedVideos": [ /* ... */ ]
}
const dataToSave = {
  voices: [], avatars: [], generatedVideos: []
};
fetch('/api/data', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify(dataToSave)
});
import requests
data = {
  "voices": [], "avatars": [], "generatedVideos": []
}
requests.post("http://localhost/api/data", json=data)
curl --request POST \
  --url http://localhost/api/data \
  --header 'Content-Type: application/json' \
  --data '{
    "voices": [],
    "avatars": [],
    "generatedVideos": []
  }'
POST

/api/model-training

上传一个音频文件以克隆/训练一个新的声音模型。

请求体 (multipart/form-data)

字段类型描述
audio_fileFile用户上传的音频文件。

成功响应 (200)

{
  "msg": "训练成功",
  "asr_format_audio_url": "...",
  "reference_audio_text": "..."
}
curl --request POST \
  --url http://localhost/api/model-training \
  --header 'Content-Type: multipart/form-data' \
  --form 'audio_file=@/path/to/your/voice.wav'
import requests
url = "http://localhost/api/model-training"
files = {'audio_file': open('my_voice.wav', 'rb')}
response = requests.post(url, files=files)
print(response.json())
import fetch from 'node-fetch';
import { FormData } from 'formdata-node';
import { fileFromPath } from 'formdata-node/file-from-path';

const form = new FormData();
form.set('audio_file', await fileFromPath('./my_voice.wav'));

fetch('http://localhost/api/model-training', {
  method: 'POST',
  body: form
});
POST

/api/upload-avatar

上传一个视频文件作为数字人形象，并为其生成缩略图。

请求体 (multipart/form-data)

字段类型描述
titleString形象名称。
video_fileFile用户视频文件。

成功响应 (200)

{
  "id": "...", "title": "我的新形象", "date": "...",
  "videoUrl": "...", "thumbUrl": "...", "videoPath": "..."
}
curl --request POST \
  --url http://localhost/api/upload-avatar \
  --form 'title="我的新形象"' \
  --form 'video_file=@/path/to/video.mp4'
import requests
url = "http://localhost/api/upload-avatar"
files = {'video_file': open('video.mp4', 'rb')}
data = {'title': '我的新形象'}
response = requests.post(url, files=files, data=data)
print(response.json())
import fetch from 'node-fetch';
import { FormData } from 'formdata-node';
import { fileFromPath } from 'formdata-node/file-from-path';

const form = new FormData();
form.set('title', '我的新形象');
form.set('video_file', await fileFromPath('./video.mp4'));

fetch('http://localhost/api/upload-avatar', {
  method: 'POST',
  body: form
});
POST

/api/audio-synthesis

根据提供的文本和参考声音模型，合成一段音频。

请求体 (application/json)

字段类型描述
textString需要转换为语音的文本。
reference_audioString参考音频文件名。
reference_textString参考音频对应文本。

成功响应 (200)

直接返回 audio/wav 格式的二进制音频流。

import java.net.http.*;
import java.net.URI;
import com.google.gson.Gson;
import java.util.Map;

var client = HttpClient.newHttpClient();
var payload = Map.of(
    "text", "你好，世界！",
    "reference_audio", "...",
    "reference_text", "..."
);
var request = HttpRequest.newBuilder()
    .uri(URI.create("http://localhost/api/audio-synthesis"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(new Gson().toJson(payload)))
    .build();
HttpResponse response = client.send(request, HttpResponse.BodyHandlers.ofByteArray());
// response.body() contains the audio data

package main
import ("bytes"; "encoding/json"; "net/http")

func main() {
    payload, _ := json.Marshal(map[string]string{
        "text": "你好，世界！",
        "reference_audio": "...",
        "reference_text": "...",
    })
    http.Post(
        "http://localhost/api/audio-synthesis", 
        "application/json", 
        bytes.NewBuffer(payload),
    )
}
<?php
$url = 'http://localhost/api/audio-synthesis';
$data = [
    'text' => '你好，世界！',
    'reference_audio' => '...',
    'reference_text' => '...',
];

$options = [
    'http' => [
        'header'  => "Content-type: application/json\r\n",
        'method'  => 'POST',
        'content' => json_encode($data),
    ],
];
$context  = stream_context_create($options);
$result = file_get_contents($url, false, $context);
// $result contains the audio data
?>
POST

/api/audition-voice

为指定声音模型生成试听音频并缓存。

请求体 (application/json)

字段类型描述
voice_idString声音模型的唯一ID。
textString试听文本。
reference_audioString参考音频文件名。
reference_textString参考音频对应文本。

成功响应 (200)

{
  "url": "/static/audition_cache/..."
}
import requests
payload = {
    "voice_id": "voice-123",
    "text": "你好，这是一个试听。",
    "reference_audio": "...",
    "reference_text": "..."
}
response = requests.post(
    "http://localhost/api/audition-voice", 
    json=payload
)
print(response.json())
curl --request POST \
  --url http://localhost/api/audition-voice \
  --header 'Content-Type: application/json' \
  --data '{
    "voice_id": "voice-123",
    "text": "你好，这是一个试听。",
    "reference_audio": "...",
    "reference_text": "..."
  }'
POST

/api/video-synthesis

提交一个视频合成任务到后台队列。

请求体 (multipart/form-data)

字段类型描述
audio_fileFile驱动口型的音频文件。
video_pathString源视频在服务器的路径。
project_titleString视频作品的标题。
avatar_idString数字人形象的ID。

成功响应 (200)

{
  "message": "Task queued successfully",
  "task_code": "..."
}
调用测试

由于文件上传的复杂性，请使用 Postman 或自定义脚本进行测试。

POST

/api/batch-progress-check

批量查询一个或多个视频合成任务的当前状态。

请求体 (application/json)

{
  "codes": ["task-code-1", "task-code-2"]
}

成功响应 (200)

[
  { "code": "...", "status": "成功", "video_url": "...", "msg": "..." },
  { "code": "...", "status": "处理中", "video_url": null, "msg": "..." }
]
